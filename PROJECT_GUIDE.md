# SERI.ET v2 — Project Guide

## Vision

SERI.ET is a premium creative education platform.

The goal is to create a cinematic, modern, and inspiring digital experience.

The website should feel like entering a creative studio, not a normal school website.

# Logo System

The SERI abstract S symbol is the primary brand element.

The logo will be used in:

- Loading screen
- Navbar
- Footer
- Favicon
- Brand animations

Only the abstract S symbol should be animated.

No full wordmark animation.
